# Thiranex Task 3 – Exploratory Data Analysis

## 📊 Project Overview

This project focuses on Exploratory Data Analysis (EDA) using a roller coaster dataset. The goal is to discover patterns, trends, and relationships through statistical analysis and data visualization.

## 🎯 Objectives

- Understand the structure of the dataset.
- Analyze missing values and data quality.
- Generate statistical summaries.
- Explore roller coaster speed, height, types, and manufacturers.
- Identify relationships between numerical features.
- Present insights through visualizations.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## 📁 Files Included

- `Thiranex_Task_3_EDA_Roller_Coaster.ipynb` – Complete EDA notebook.
- `coaster_db.csv` – Dataset used for analysis.

## 📈 Analysis Performed

1. Dataset inspection
2. Missing-value analysis
3. Data cleaning
4. Statistical analysis
5. Status distribution
6. Manufacturer analysis
7. Speed distribution
8. Height vs Speed analysis
9. Correlation heatmap
10. Location analysis
11. Roller coaster type comparison
12. Key findings and conclusion
